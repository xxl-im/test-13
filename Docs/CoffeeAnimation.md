# 咖啡手语动作优化说明

## 工作范围

本文件记录了对“咖啡”手语动作的 Blender 后处理优化工作。
在此之前，团队已基于 MediaPipe 的实时关键点输出，完成了从原始姿态数据到数字人骨骼驱动的基础映射。本阶段的工作是在该映射生成的骨骼动画基础上，对手部姿态进行专项优化，使其更符合手语表达的准确性要求。

## 已完成的优化内容

- 未向人物右手手腕骨骼写入额外的旋转偏移，以避免改变原动画中手腕的朝向。
- 保持右手拇指与食指在整个动作过程中处于伸展状态。
- 在动作的中段阶段，使右手中指、无名指、小指向掌心方向弯曲，以形成更清晰的手语手型。
- 将调整后的动画数据保存为独立的 Blender 源文件，便于后续复核与导出。

## 验证方式

随附的预览图展示了某一关键帧的手型与手腕方向，供初步检查。完整的动作质量仍需在 Blender 时间轴中进行逐帧播放验证，并在导入 Unity 后，结合实际场景进行运行测试，以确认其在目标环境中的表现一致性。

## 当前限制

- 原始动作数据来源于单目 MediaPipe 的关键点估计，当双手发生遮挡或手臂朝向摄像头时，上肢的深度信息与前臂的扭转角度仍可能存在误差。
- 本次调整仅涉及手指姿态的修正，不改变团队已有的“关键点到骨骼”基础映射流程。
- 当前 Blender 文件为复核用途的源资产。在接入 Unity 前，需从此版本重新导出 FBX 文件，并在引擎中进行完整的播放与交互测试。
